## AI Models Used & Selection Rationale

### 1. Gemma (Google Gemma Family)
- **Model:** Google Gemma (Gemma 2 2B / 9B, CodeGemma)
- **Deployment Mode:** 100% Local on-device inference (via Ollama)
- **Role in Project:** Core local reasoning engine, offline intelligence, task orchestration, and context comprehension for Jinn.
- **Reasons for Selection:**
  - **Optimized for Local Laptop Hardware:** Gemma models (especially 2B and 9B) offer an exceptional performance-to-size ratio, running smoothly on consumer laptops with low memory footprints and fast token generation speeds.
  - **Zero Data Egress & 100% Privacy:** By running completely offline and locally on the laptop, user interactions and sensitive data never leave the local environment.
  - **High-Quality Reasoning & Instruction-Following:** Gemma delivers superior reasoning, comprehension, and structured output formatting even in quantized local environments.
  - **Cost-Free & Resilient:** Eliminates cloud API dependencies, rate limits, latency bottlenecks, and inference costs, enabling seamless always-available local AI utility.
